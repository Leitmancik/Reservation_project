# Reservation Project

Streamlit aplikace.

## Lokální spuštění

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Nasazení

Nasazeno na Streamlit Community Cloud ze souboru `streamlit_app.py` na větvi `main`.
Každý push do `main` nasadí novou verzi automaticky.
